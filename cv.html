Selected Public Projects
Enterprise NFR Agent Platform
Public technical demonstrator · https://github.com/tzijlstra-acn/RealAIInfrastrucure
  • Enterprise platform built around multiple AI agent workflows, each handling a different NFR domain, with a shared knowledge graph, document intelligence, regulatory analysis, human approval gates, and enterprise integration patterns. Built as a technical demonstrator of what a production-grade enterprise AI stack looks like in practice.

DORA Article 12 AI Control Line
Enterprise workflow demonstrator · https://github.com/tzijlstra-acn/ProReinsuranceAIWorkflow
  • A fully functional AI workflow demonstrator built around a real regulatory requirement (DORA Article 12). Uses synthetic and anonymized data throughout. Takes a regulatory input through AI-generated control updates, infrastructure proposals, policy-engine verification, compliance documentation, human approval gates, and a complete traceable evidence chain.
  • Commercial relevance: Demonstrates the full architecture of an enterprise AI workflow: model integration (OpenAI o3 for regulatory reasoning, GPT-4o for infrastructure, GPT-4o-mini for documentation), an 11-state machine for end-to-end traceability, and human approval gates at every consequential step. Built using only synthetic and anonymized data.
  • Note: Demonstrator using synthetic and anonymized data · no client systems, credentials, or confidential information · integration patterns are illustrative
Enterprise AI Economics Simulator
Public executive decision tool · https://github.com/tzijlstra-acn/AICostSimulator
  • Interactive tool for modelling the full economics of an enterprise AI platform: model selection and routing, token costs, cloud vs. sovereign vs. on-premise hosting, shared infrastructure costs, governance overhead, and net value projections. Built for executive decision-making and proposal development.
  • Commercial relevance: Useful for buyers and architects who need to model the full economics of an AI platform investment: not only capability but also what shared infrastructure and governance overhead do to unit economics.
  • Note: All prices, benchmarks, gains, and allocation values are illustrative planning assumptions.
